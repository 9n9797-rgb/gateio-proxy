# Gate.io AI Trading Autopilot

نظام تداول آلي على Gate.io مزوّد بمحرك قرار تكيّفي (يتعلّم من نتائج صفقاته
السابقة) وطبقة ذكاء صناعي اختيارية (LLM)، مع إدارة مخاطر ثابتة لحماية رأس
المال، وقابل للنشر على أي VPS.

## أوضاع التشغيل

| الوضع | الوصف |
|---|---|
| `off` | متوقف تماماً (الافتراضي) |
| `signal` | يحلل ويسجّل الإشارات فقط بدون أي تنفيذ |
| `paper` | محفظة وهمية كاملة (شراء/بيع تجريبي) لتطوير الذكاء الصناعي بدون مخاطرة |
| `live` | تنفيذ صفقات حقيقية على حسابك في Gate.io (معطّل افتراضياً، راجع الأمان أدناه) |

## كيف "يتعلّم" النظام من أخطائه

كل مؤشر فني (RSI, MACD, الاتجاه, OBV) له وزن في معادلة القرار. عند إغلاق أي
صفقة (وهمية أو حقيقية)، تُحدَّث الأوزان تلقائياً في `lib/strategy.js`:
المؤشرات التي أعطت إشارة صحيحة في صفقة رابحة يزيد وزنها، والتي تسببت بصفقة
خاسرة يقل وزنها. هذا يجعل القرار المستقبلي يتفادى أنماط الإشارات التي سبق
أن تسببت بخسارة لهذا الزوج. إن أضفت `OPENAI_API_KEY` يضيف النموذج اللغوي
طبقة تفسير/تأكيد فوق هذا القرار الكمّي مع الاطلاع على ملخص الأخطاء السابقة.

## الأمان وإدارة المخاطر

- وضع `live` معطّل تماماً ما لم تضبط `AUTOPILOT_ALLOW_LIVE=true` في `.env` عمداً.
- حدود ثابتة (قابلة للتعديل عبر `.env`): نسبة مخاطرة لكل صفقة، وقف خسارة،
  جني ربح، أقصى عدد مراكز مفتوحة، وقاطع دائرة يومي (Daily Loss Breaker)
  يوقف التداول تلقائياً إذا تجاوزت الخسارة اليومية الحد المسموح — بغض
  النظر عن مدى "ثقة" الذكاء الصناعي بالقرار.

## التشغيل محلياً

```bash
cp .env.example .env   # ثم عدّل القيم
npm install
npm start
```

## النشر على VPS

### الطريقة 1: Docker (الأسهل)
```bash
cp .env.example .env   # عدّل القيم
docker compose up -d --build
```

### الطريقة 2: سكربت تثبيت جاهز (Ubuntu/Debian)
```bash
sudo bash deploy/setup-vps.sh
```
يثبّت Node.js، ينسخ المشروع إلى `/opt/gateio-autopilot`، ويشغّله كخدمة
systemd دائمة (`gateio-autopilot.service`) تعمل تلقائياً بعد كل إعادة إقلاع.

### الطريقة 3: PM2
```bash
npm install -g pm2
pm2 start ecosystem.config.cjs
pm2 save && pm2 startup
```

## أهم نقاط API

| Endpoint | الوصف |
|---|---|
| `GET /autopilot/status` | الوضع الحالي، المراكز المفتوحة، آخر تشغيل |
| `POST /autopilot/mode` `{ "mode": "paper" }` | تغيير الوضع |
| `POST /autopilot/pairs` `{ "pairs": ["BTC_USDT"] }` | تحديد الأزواج المتابَعة |
| `GET /autopilot/portfolio` | المحفظة الوهمية: السيولة، المراكز، الربح/الخسارة |
| `POST /autopilot/portfolio/reset` | تصفير المحفظة الوهمية |
| `GET /autopilot/trades?limit=50` | سجل الصفقات المغلقة |
| `GET /autopilot/weights` | الأوزان التي تعلّمها النظام لكل مؤشر |

نقاط `/proxy/*` الأصلية (الأرصدة، الأوامر، التحليل) ما زالت تعمل كما هي.
